* Ability to "look" in a room to get a more detailed description of everything. For instance, agents would always have a general knowledge of the layout of the map, but they may not be able to see more detailed descriptions without being there. This probably requires splitting areas/rooms into a general broad descrpition agents are always aware of and a more detailed description that may change from time to time. If the general store is closed, the agent would not know that (they would just know of the existence of the general store) until they went to the village and were able to "look" in more detail. Looking should be a free action. Agents should be aware of looking as a tool they can use. This is also needed so that we can have large numbers of detailed objects in a single room without flooding the agent context
* Items - have arbitrary items with descriptions and "condition" that can be carried or placed. This enables owning or purchasing things, and things becoming broken or dirty or repaired. Descriptons should be unusual to change, conditions might change frequently. Unknown how agents would change items (for instance a worker dusting a display shelf), perhaps this needs to be adjucated by an GM judge. Using an LLM GM as the judge would permit this to be somewhat freeform, and keeping descriptoins separate and more restricted against modification would keep items from drifting into completely different forms over time. For now agents can carry unlimited items.
* Single room communication in between agent-to-agent whisper and area wide shouting, if it doesn't exist. Eventually this should be the default to avoid flooding agents with every other agent's communication
* Hiring - It should be possible to hire new staff. For now, no salaries. Requires "generating" a new agent.
* Random personality characteristics at spawn - Need to source a list somewhere and add them to description. This would allow an agent to "interview" other agents and decide who to hire
* Time budgets - Need something more complex that allows for instance, a multi-turn speech exchange within one turn, or a budget to perform a certain number of actions, like applying changes to many things in a room (see "Items" above), in one turn, so that the agent can choose a set of actions and then do them. Right now agents often deliberate over whether they should "spend" their 30 minute turn speaking, or walk around first, which seems like a waste. Should come up with some set of rules to for instance, allowe them to announce where they are going and move in the same turn, so they don't contemplate coordination dillemas when attempting to travel together somewhere.
